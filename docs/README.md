## **Тестирование кодов**

#### ТЕСТЫ ДЛЯ КЛАССА Product

1. Проверка корректности инициализации Product через параметризацию данных
2. Проверка атрибутов продукта, созданного через фикстуру

#### ТЕСТЫ ДЛЯ ПРИВАТНОГО АТРИБУТА ЦЕНЫ И СЕТТЕРА
1. Проверка, что атрибут цены является приватным (через property).
* Проверяем, что price - это property (геттер), а не обычный атрибут.
* Приватный атрибут должен существовать с манглингом.
2. Проверка работы геттера цены.
3. Сеттер должен принимать положительную цену.
4. Сеттер не должен устанавливать цену 0 и должен вывести сообщение.
5. Сеттер не должен устанавливать отрицательную цену.
6. При понижении цены и согласии пользователя цена должна измениться.
7. При понижении цены и отказе пользователя цена не должна измениться.
8. При повышении цены подтверждение не требуется.

#### ТЕСТЫ ДЛЯ КЛАСС-МЕТОДА new_product
1. Класс-метод new_product должен создавать объект Product из словаря.
2. При наличии дубликата количество должно складываться.
3. При конфликте цен должна выбираться более высокая.
4. Если дубликата нет, создаётся новый объект.

#### ТЕСТЫ ДЛЯ ПРИВАТНОГО АТРИБУТА products

1. Проверка, что список товаров является приватным атрибутом.
2. Геттер products должен возвращать строку в правильном формате.
3. Для пустой категории геттер должен возвращать пустую строку.

#### ТЕСТЫ ДЛЯ МЕТОДА add_product

1. Метод add_product должен добавлять продукт в приватный список.
2. Метод add_product должен увеличивать счетчик product_count.
3. Метод add_product не должен возвращать значение (возвращает None).
* Вызываем метод — он не возвращает значение (сигнатура -> None)
* Проверяем, что продукт действительно добавлен
4. Метод add_product должен принимать объект Product.

#### ТЕСТЫ ДЛЯ АТРИБУТОВ КЛАССА (СЧЕТЧИКИ)

1. Проверка автоматического подсчета категорий и товаров через параметризацию
2. Проверка счетчиков с использованием фикстур
 
#### Проверка успешной загрузки данных из реального файла products.json. 
Проверяет создание объектов и обновление счетчиков класса.
Тест 1: Проверяем, что вернулся список
Тест 2: Проверяем типы объектов внутри списка
* * products теперь строка (геттер), а не список
* Приватный список товаров должен быть списком объектов Product
Тест 3: Проверяем, что атрибуты класса обновились корректно
Проверка корректной обработки отсутствия файла. Функция должна выбросить FileNotFoundError с понятным сообщением.

#### НОВЫЕ ТЕСТЫ ДЛЯ НОВОГО ФУНКЦИОНАЛА

1. Проверка, что после загрузки из JSON геттер products возвращает строку
    в правильном формате: 'Название, X руб. Остаток: X шт.\n'.
2. Проверка, что у загруженных из JSON продуктов цена является приватным атрибутом
3. Проверка, что после загрузки из JSON сеттер цены работает корректно
    (включая проверку на отрицательные значения).
4. Проверка согласованности счётчиков после загрузки из JSON:
    product_count должен равняться сумме длин приватных списков всех категорий.
5. Проверка, что к загруженной из JSON категории можно добавить товар
    через метод add_product и счётчик обновится корректно.
6.  Тест загрузки с использованием мокированного JSON-файла через tmp_path.
    Позволяет проверить работу функции без зависимости от реального файла.
